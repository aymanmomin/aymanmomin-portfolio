# Changelog

All notable changes are recorded here. Format based on Keep a Changelog.

## [Unreleased]
### Added
- Repository configuration, documentation and PR template
- Vite, React, TypeScript and ESLint scaffold
- Tailwind CSS and Vitest
- GitHub Actions CI (lint, test, build)
- Design tokens, self-hosted fonts, UI primitives, responsive navbar and page shell
- Hero section with a lazy-loaded interactive 3D network graph and a static SVG fallback
- About, Education, Skills, Experience, Projects and Contact sections
- Story site foundation: content model, word-count budgets, media slot, accessible dialog, claims register
- Express route: eleven stops with copy, stats, pop-ups, an agency income currency toggle and an animated SEO staircase
- Scroll-driven 3D world behind the story (Mumbai, a night crossing, Calgary), with a camera that follows scroll and an India / The Crossing / Canada progress bar

### Changed
- Replaced Vite starter content with a placeholder page
- Set page title, description and theme colour
- Site direction changed to a single-page, scroll-driven story; the station-snapping prototype was never merged
- The story is now the default view; the earlier standard layout is at `?story=0`
